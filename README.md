# Global Market Platform

Global multilingual market platform for precious metals, markets, news, gemstones, and digital reference-price displays.

Current source baseline: V0.3.2.

Architecture target: Next.js + TypeScript, Supabase, Vercel, centralized market-data engine, and secure display pairing.

Country, language, and display currency are independent user choices. Commercial brand and domain are intentionally not finalized yet.

Vercel Git integration is connected to the `main` branch for automatic deployments.
